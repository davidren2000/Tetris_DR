本游戏是一个经典的俄罗斯方块（Tetris）浏览器版本，支持键盘和触屏操作。
玩家通过左右移动、旋转和加速下落方块，使不同形状的方块排列成完整的横行。
每完成一行，得分增加。游戏结束后会显示当前得分，并可以点击按钮重新开始。
This is a classic Tetris browser-based game that supports both keyboard and touch controls.
Players move, rotate, and drop blocks to complete full horizontal lines with different shaped pieces.
Each completed line increases your score. After the game ends, your final score is displayed, and you can restart with one click.
